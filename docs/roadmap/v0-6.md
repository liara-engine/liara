Up to here the engine runs from a developer build. v0.6 makes it distributable: a Linux user installs it from the AUR, a Windows user extracts an archive and runs a sample.

## Scope

CMake `install` rules for every module, so that `find_package` works in a third-party project. The AUR `PKGBUILD` and the Windows packaging script arrive in the meta repository's `packaging/`.

The composition tool graduates from its experimental form: it assembles a user-selected combination on both platforms, with diagnostics good enough for someone who is not me.

## The tools disappear

Every developer tool introduced from v0.2 to v0.5 (stats overlay, log console, settings inspector, asset browser, debug primitives, input visualizer, audio panel, material inspector) is compiled out of release builds through a CMake option, or reachable only behind an explicit debug toggle that is off by default in release.

The shipped sample game displays no developer overlay on launch, and verifying that is a Definition of Done item rather than an assumption.

One exception survives into release builds: a small release-diagnostics panel behind a key combination an end user is unlikely to find by accident, exposing the engine version, GPU information, and a way to dump a crash report. It is the only developer-facing tool that ships with the runtime.

## Out of scope

Flatpak and Snap, deferred indefinitely. macOS packaging, out of scope. A Windows MSI installer, deferred, since a portable archive is enough. Code signing, deferred. Auto-update, out of scope.

## Definition of Done

- [ ] CMake install works for every module.
- [ ] `find_package` works in a third-party project.
- [ ] The AUR PKGBUILD builds and installs.
- [ ] The Windows portable archive runs on a clean Windows 11 machine.
- [ ] The sample game runs from both the AUR install and the Windows archive.
- [ ] Every developer tool is compiled out of release builds or hidden behind a toggle that is off by default.
- [ ] The shipped sample game shows no developer UI on launch.
- [ ] The release diagnostics panel works and is reachable through the documented key combination.
- [ ] The user documentation has "Distributing your game".
- [ ] The composition tool assembles a user-selected combination on both platforms, with clear diagnostics for the combinations it rejects.
