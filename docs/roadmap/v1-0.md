The first stable release. The promise: a sufficiently motivated developer can build a small 3D game with Liara, ship it on the AUR or as a Windows archive, and not feel cheated.

## Scope

v1.0 is mostly quality and stability on top of v0.9. The features are essentially v0.9's, and what changes is the discipline.

Documentation becomes complete: every public function in `liara-interfaces` carries Doxygen documentation, and the user documentation covers the full feature set with tutorials.

Stability becomes a criterion: no known crashes in normal operation, clean Vulkan validation, tracked memory leaks.

The API freezes. From v1.0 the meta repository follows strict semantic versioning, and a breaking change means a major bump.

The compatibility record is finalised for the first stable combinations of module versions.

## What v1.0 is not

It is not feature-complete. It is not the editor. It has no PBR, no shadow mapping, no post-processing, no scripting and no physics.

It is first usable rather than first complete, and that distinction is carried in the version number rather than glossed over in the announcement.

## Definition of Done

- [ ] The sample game from v0.9 is finished and polished.
- [ ] It is published on the AUR and as a Windows archive.
- [ ] Every public symbol in `liara-interfaces` is documented.
- [ ] The user documentation covers every v0.x feature with tutorials.
- [ ] No known crashes in the sample game.
- [ ] Memory leak detection is clean for it.
- [ ] Every module repository is tagged at its compatible version.
- [ ] The meta repository is tagged `v1.0.0`.
- [ ] A release note describes what v1.0 is and what it is not.
